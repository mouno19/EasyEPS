# Security Policy

## Scope

EasyEPS includes authentication, learner profiles, progress history, study plans, certificates, avatar uploads, admin routes, and a server-side AI-tutor integration. Security reports about this repository or its deployed application are welcome.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/mouno19/EasyEPS/security/advisories/new), when available. If that option is unavailable, open a minimal issue asking for a private contact channel without including exploit details.

Please include:

- A clear description of the issue and its potential impact
- Affected route, component, or commit, if known
- Reproduction steps or a minimal proof of concept
- Any suggested mitigation

Do not include real learner data, credentials, API keys, or other secrets in a report.

## Response expectations

Maintainers will acknowledge a valid report as soon as practical, investigate it, and coordinate remediation or disclosure timing with the reporter. Please allow reasonable time for a fix before public disclosure.

## Safe testing

Only test accounts and data you own. Do not access, modify, download, or delete another learner's data; do not perform denial-of-service testing; and stop immediately if you encounter personal information or secrets.
